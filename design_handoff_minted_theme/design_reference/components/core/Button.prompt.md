Minted's action button — use for any clickable action; labels are sentence-case verbs.

```jsx
<Button onClick={save}>Add an investment</Button>
<Button variant="secondary" size="sm">View all</Button>
```

Variants: `primary` (mint fill — only one per region), `secondary`, `ghost`, `danger`. `full` stretches; `size="sm"` for inline/table actions.
