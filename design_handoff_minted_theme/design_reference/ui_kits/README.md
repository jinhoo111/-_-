# Minted UI kit

Interactive click-through of the Minted app (dark primary). Open `index.html`.

- `LoginScreen.jsx` — sign in → enters the app
- `AppShell.jsx` — top nav (wordmark, sections, theme + KR-color toggles, log out)
- `PortfolioScreen.jsx` — dashboard: stat row, holdings, allocation, next-step nudge
- `IndicesScreen.jsx` — market index grid + category filters + yield curve card
- `NewsScreen.jsx` — filtered news list + analyst pulse
- `JournalScreen.jsx` — calendar with entry dots, day panel (trades + notes), streak stats
- `FlowScreen.jsx` — insider trades / fund 13F tables + weekly summary
- `MonitorScreen.jsx` — watchlist with mini sparklines + alerts, radar signals, memos

All six app sections are designed. Toggles in the settings gear switch `data-theme` and `data-price-convention` live.
